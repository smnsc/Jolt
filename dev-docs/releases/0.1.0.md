# Jolt 0.1.0

Your Jira issues. One shortcut away.

- Native Jira Cloud search with a configurable global shortcut.
- Project, issue type, assignee, and reporter shortcuts with autocomplete.
- Issue previews and quick copy/open actions.
- Automatic update checks, optional automatic installation, and manual checks.
- Optional support through Ko-fi. Free and open source under the MIT license.

Requires macOS 14 or later. Universal build for Apple Silicon and Intel.

Jolt is not Apple-notarized. If macOS blocks the app, attempt to open it, then use
System Settings → Privacy & Security → Open Anyway. Move Jolt to Applications
before running it or using the updater.

You may need to reconnect Jira after updates. Existing development builds using
the old bundle identifier start with fresh preferences; disable their launch-at-login
setting before replacing them.
