# Jolt 0.1.2

This release improves update preferences and fixes website download links.

- Choose when to check for updates: On Launch, Daily, Monthly (every 30 days), or Never. Daily remains the default, and manual checks are always available.
- Automatic download and installation are disabled, including previously enabled preferences. Updates require your confirmation.
- Website download buttons refresh from the release feed before deployment, even when uploaded HTML wraps or reorders their attributes.
- Build numbering returns to short, sequential numbers, starting with build 116.

## One-time manual installation

Existing installations with timestamp build numbers, such as 1791449100, cannot
automatically update to build 116. Download Jolt 0.1.2 from
[the website](https://smnsc.github.io/Jolt/), quit Jolt, open the DMG, and replace
Jolt in Applications. Launch the replacement app and confirm Settings shows
version 0.1.2+build.116.

After this one-time installation, future updates can be offered normally according
to your chosen update-check frequency. You may need to reconnect Jira.

Requires macOS 14 or later. Universal build for Apple Silicon and Intel.

Jolt is not Apple-notarized. If macOS blocks the app, attempt to open it, then use
System Settings → Privacy & Security → Open Anyway. Move Jolt to Applications
before running it or using the updater.
