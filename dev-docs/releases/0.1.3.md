# Jolt 0.1.3

- Settings now displays the version as **Version 0.1.3 (build 119)**.
- App version and build numbers are tracked with the source, so clearing build files no longer resets numbering. Release builds verify that their version matches the committed source.
- Developer build and versioning instructions are grouped in the README’s developer section.

Requires macOS 14 or later. Universal build for Apple Silicon and Intel.

Jolt is not Apple-notarized. If macOS blocks the app, attempt to open it, then use
System Settings → Privacy & Security → Open Anyway. Move Jolt to Applications
before running it or using the updater. You may need to reconnect Jira after updating.
