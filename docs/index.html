GET STARTED

Set up Jolt in three steps.

For macOS 14+ and Jira Cloud.

Download Jolt ↓

  1. Install

    Open the downloaded DMG and drag Jolt into Applications.

  2. Open

    Launch Jolt. If macOS blocks it, go to System Settings → Privacy & Security → Open Anyway.

  3. Connect

    Enter your Jira site, email, and API token. Then press ⌥ J to search.

Mac prompts: Jolt isn’t Apple-notarized; only approve a download you trust. First-launch help ↗ If Keychain asks for Jolt’s saved credentials, use your Mac login password and choose Allow.

Bring it all together

Why an API key?

An API key (Atlassian calls it an API token) lets Jolt connect directly to Jira on your behalf.

Atlassian’s documented Jira OAuth 2.0 (3LO) browser sign-in flow requires an app client secret. A distributed Mac app cannot keep that shared secret private. Supporting this flow safely would require a hosted authentication service, which Jolt does not have, so Jolt uses a personal API token instead.

You stay in control.

Your token is stored in macOS Keychain and sent only to Atlassian. Jolt only reads Jira data; it does not change issues, even if your token grants broader permissions.

You can revoke your token at any time in your Atlassian API token settings.

Your work stays yours.

Jolt reads issues; it never changes them. Credentials stay in macOS Keychain. Jira requests go to Atlassian. Update checks contact GitHub; no Jira credentials are sent with them. This website uses no analytics or cookies.

Jolt checks for updates automatically. You can turn checks off or opt into automatic installation in Settings. You may need to reconnect Jira after an update.
