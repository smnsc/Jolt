READY WHEN YOU ARE

Make yourself at home.

You’ll need a Jira Cloud account and an Atlassian API token.

  1. Download and move to Applications.

    Get the DMG from GitHub Releases, open it, and drag Jolt into Applications.

  2. Allow Jolt on your Mac.

    Jolt is not Apple-notarized. After attempting to open it, go to System Settings → Privacy & Security → Open Anyway if macOS blocks it. Apple’s instructions ↗

  3. Connect your Jira account.

    Enter your Jira site, account email, and API token. Press ⌥ J and find your first issue.

Your work stays yours.

Jolt reads issues; it never changes them. Credentials stay in macOS Keychain. Jira requests go to Atlassian. Update checks contact GitHub; no Jira credentials are sent with them. This website uses no analytics or cookies.

Jolt checks for updates automatically. You can turn checks off or opt into automatic installation in Settings. You may need to reconnect Jira after an update.
